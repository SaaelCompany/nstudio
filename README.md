# NStudio

Ядро для программ и игр, которые собираются визуально. Сейчас это конструктор сцены, исполнитель графа, реестр плагинов и редактор. Физика, ввод и игровой цикл сюда не входят: их позже добавляют плагины.

## Запуск

```bash
npm install
npm run dev
```

Проверки: `npm test`. Сборка: `npm run build`.

Редактор открывается на макете примера: земля, фигура игрока и заголовок. Вкладка **События** показывает лист этого макета: «Старт» печатает приветствие и сумму 2 + 40. У каждого макета свой лист. Кнопка **Запуск** выполняет событие `start` активного макета. Проект сохраняется в браузере и в файл `*.nstudio.json`.

## Как устроен граф

У ноды одна из четырёх ролей:

- **event** — вход в программу. Ядро знает событие `start`. Хост или плагин может послать своё, например `tick`.
- **exec** — выполняется, когда на вход приходит поток, и сама зажигает выходы потока.
- **pure** — без потока. Результат вычисляется в момент, когда следующая нода читает выход.
- **inert** — только свойства на холсте. Исполнитель такие ноды пропускает.

Провода потока задают порядок. На вход потока можно подать несколько проводов: нода сработает на каждый. Провода данных читаются, когда нода спрашивает вход, и у такого входа провод один. Выход можно раздать нескольким нодам. Цикл по данным — ошибка. Цикл по потоку останавливается лимитом шагов, программа не зависает.

Документ — это JSON версии 1: ноды, связи, переменные, макеты в поле `scenes` и поле `extensions`. Лист событий лежит на макете (`scenes.scenes[].nodes` и `edges`). Поля нод и связей на корне документа повторяют лист активного макета, чтобы старый файл открывался. Если у макетов ещё нет `nodes`, граф с корня переносится на активный макет. В `extensions` плагин хранит свои данные проекта, ядро их не разбирает. Неизвестный тип ноды не выбрасывается: проект открывается, а проверка просит подключить плагин. Файл без `scenes` открывается с пустым макетом.

## Плагины

Плагин — обычный TypeScript-модуль. Файл проекта код не исполняет.

```ts
import { definePlugin, Engine, stringValue } from './core'

export const notes = definePlugin({
  id: 'example.notes',
  name: 'Заметки',
  version: '0.1.0',
  register(api) {
    api.registerCategory({ id: 'examples', label: 'Примеры', color: '#7f8c99' })
    api.registerNodeType({
      id: 'example.note',
      title: 'Заметка',
      category: 'examples',
      description: 'Текст на графе.',
      role: 'inert',
      inputs: [],
      outputs: [],
      properties: [
        { id: 'text', label: 'Текст', dataType: 'string', defaultValue: stringValue('Заметка'), widget: 'text' },
      ],
    })
  },
})

const engine = new Engine()
engine.use(notes)
```

Регистрация идёт в таком порядке: категории, типы данных, ноды. Если `register` бросает ошибку, ядро откатывает всё, что плагин успел добавить. Повторно тот же `id` подключить нельзя.

Чистая нода не должна ничего менять: исполнитель может вызвать `compute` несколько раз. Событийная нода с методом `execute` сама решает, когда звать `trigger`. Поле `payload` приходит от хоста, например `{ dt: 0.016 }` для будущего кадра игры.

В редакторе кнопка **Модули** показывает каталог. «Подключить» регистрирует модуль из каталога: `src/example-plugin.ts` добавляет ноду «Заметка», `src/example-modules.ts` — свечение и отскок. Свой код из файла проекта не запускается.

Плагин может добавить вид объекта на сцену:

```ts
api.registerSceneObject({
  id: 'game.coin',
  title: 'Монета',
  description: 'Круглая награда.',
  defaultWidth: 48,
  defaultHeight: 48,
  defaultProps: { fill: '#e0b03a' },
  fields: [{ id: 'fill', label: 'Цвет', kind: 'color' }],
})
```

Если `register` падает, вид объекта откатывается вместе с нодами плагина. В проекте вид становится типом объекта, а на макете стоит экземпляр: у него свои координаты и копия свойств. Незнакомый вид рисуется рамкой, данные не теряются.

Эффект и поведение регистрируются так же:

```ts
api.registerEffect({
  id: 'game.effect.glow',
  title: 'Свечение',
  description: 'Цветная тень на макете.',
  fields: [{ id: 'radius', label: 'Радиус', kind: 'number' }],
  defaultProps: { radius: 12 },
  filter: (props) => `blur(${props.radius}px)`,
})

api.registerBehavior({
  id: 'game.behavior.solid',
  title: 'Твёрдое',
  description: 'Метка для модуля столкновений. Ядро само объекты не двигает.',
  fields: [],
  defaultProps: {},
})
```

`filter` нужен только предпросмотру макета и в файл не пишется. Эффект крепится к экземпляру, один вид можно повесить несколько раз. Поведение крепится к типу объекта и общее для его экземпляров; повтор того же вида не добавляется. Ядро хранит параметры поведения и не запускает физику.

## Конструктор сцены

Макет — это прямоугольник на сером поле. Слева свойства макета и объекта, справа проект и слои, над холстом вкладки **Макет** и **События**. У каждого макета свой лист: переключение макета меняет граф, добавление макета открывает пустой лист. Объекты стоят в своих размерах: их двигают, тянут за края и поворачивают ручкой над рамкой. Shift при повороте ставит угол на 15°. В свойствах включаются сетка и привязка, шаг по умолчанию 32 пикселя, а у выделенного объекта — эффекты и поведения. Колёсико масштабирует вид, средняя кнопка и пустое поле вокруг макета его сдвигают. Рамка на пустом месте макета выделяет несколько объектов. Внизу строка состояния показывает координаты мыши, активный слой и масштаб.

Слои рисуются снизу вверх. В списке верхний слой — передний. Заблокированный слой не принимает новые объекты и не двигается мышью. Скрытый слой не виден. Удаление слоя переносит его объекты на оставшийся.

Встроенные виды: **Фигура** (прямоугольник и эллипс), **Текст**, **Спрайт**. Картинка спрайта хранится в файле проекта. Стрелки двигают выбор на пиксель, Shift — на шаг сетки, Ctrl+D копирует, Delete удаляет.

Встроенные эффекты рисуются на макете: размытие, яркость, оттенки серого, оттенок. Встроенные поведения только помечают тип: пуля, перетаскивание, твёрдое.

## Встроенные ноды

События: Старт. Поток: последовательность, ветвление, повтор. Данные: число, строка, логическое, склейка текста. Математика: сложение, вычитание, умножение, деление, остаток, сравнение. Логика: и, или, не. Переменные: прочитать и записать. Отладка: печать в консоль запуска.

## Что остаётся плагинам

Ввод, физика, звук и игровой цикл сюда не входят. Плагин регистрирует свои ноды, виды объектов, эффекты и поведения, а хост вызывает `engine.run(document, { event, payload })` для листа активного макета.
